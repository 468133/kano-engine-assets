# kano-engine-assets

KANO 流量监控引擎资源仓库 —— 为 UFI-TOOLS「设备流量监控插件」提供后台统计引擎与云端更新支持。

---

## 简介

本仓库托管 `kano_engine`（后台 C 二进制统计引擎）及其配套资源，通过 jsDelivr CDN 分发，支持插件一键云端部署、自动更新与版本管理。

引擎直读内核 `/proc/net/nf_conntrack` 与 WAN 口 sysfs，实现：
- **页面关闭期间持续统计**（解决传统 iptables 计数页面关闭即中断的问题）
- **按 MAC 聚合多 IPv4/IPv6 地址**（精准跟踪临时 IPv6 轮换设备）
- **自动回退机制**（引擎异常时无缝回退 iptables 计数链，数据不丢）

## 使用教程

### 1. 下载最新版插件

直接下载本仓库根目录下的 **「设备流量监控插件」JS 文件**（文件名格式：`设备流量监控插件vXX.X.X.js`），即为最新完整版插件，无需额外下载引擎。

> 插件已内置引擎云端部署功能，首次使用时会自动引导安装。

### 2. 导入 UFI-TOOLS

1. 打开 UFI-TOOLS 管理后台
2. 进入「插件」或「自定义头部」页面
3. 将下载的 `.js` 文件内容粘贴导入（或使用文件导入功能）
4. 保存并刷新页面

### 3. 开启高级功能（Root）

本插件依赖 iptables 和内核 conntrack 支持，**必须先在 UFI-TOOLS 主界面开启「高级功能」**（获取 root 权限），否则流量统计和限速功能无法工作。

### 4. 安装统计引擎（推荐）

插件导入后，展开「设备流量监控」面板：
1. 点击 **「🛠️ 引擎」** 按钮
2. 在弹窗中点击 **「⬇️ 云端安装」**
3. 等待自动下载并部署 `kano_engine` 后台引擎
4. 安装完成后引擎会自动启动，并写入开机自启

> 引擎安装后，即使关闭浏览器页面，后台仍会持续统计流量，重开页面自动同步。

### 5. 开启自动监控

点击 **「自动监控」** 按钮，插件将按设定间隔（默认 5 秒）自动刷新设备列表、同步 iptables 规则、更新流量数据并渲染图表。

- **不开启自动监控**：屏幕不会自动刷新，新设备不会自动出现，IP 轮换后规则不会自动更新，限速可能失效
- **开启后**：支持实时速率显示、自动归档、限速规则重建、新设备自动发现

### 6. 常用功能速览

| 按钮 | 功能 |
|------|------|
| 🔄 刷新 | 手动执行一次完整同步（设备发现 + 规则同步 + 流量更新） |
| 🛠️ 引擎 | 引擎状态面板、云端安装/更新/卸载、自检、连通性测试 |
| 📋 归档并重计 | 保存当前流量快照，然后清零计数器重新开始统计 |
| 📋 查看历史 | 查看所有归档记录，支持回添、删除、按上传者筛选 |
| 🏆 流量排行 | 当前流量 / 累计流量排行，支持在线/离线设备 |
| ⏱️ 限速 | 单设备限速（上行/下行，支持 KB/s/MB/s/Kbps/Mbps） |
| ✏️ 改名 | 自定义设备名称（自定义名 > 接入设备名 > DHCP租约名 > 历史名） |
| ⚙️ 设置 | 自动归档时间、IPv6 开关、刷新间隔、日志保留天数、手机视图 |

## latest.json 格式说明

```json
{
  "rev": "21.0.4",
  "guard": "https://cdn.jsdelivr.net/gh/468133/kano-engine-assets@main/binaries/kano_engine",
  "deploy": "https://cdn.jsdelivr.net/gh/468133/kano-engine-assets@main/deploy/deploy.sh",
  "js": "https://cdn.jsdelivr.net/gh/468133/kano-engine-assets@main/js/patch_v21.0.4.b64",
  "jsRev": "21.0.4",
  "md5": "a1b2c3d4e5f6...",
  "notes": "修复自更新大文件通道、引擎看门狗"
}
```

| 字段 | 说明 |
|------|------|
| `rev` | 引擎版本号 |
| `guard` | 引擎二进制 base64 下载地址 |
| `deploy` | 设备侧部署脚本下载地址（curl 兜底） |
| `js` | 插件 JS 更新包 base64 地址 |
| `jsRev` | 插件版本号（独立于引擎版本） |
| `md5` | 引擎二进制校验值（全零占位则跳过校验） |
| `notes` | 更新说明（弹窗展示） |

## 分发节点

插件内置多 CDN 节点轮询，国内优先走镜像：

- `cdn.jsdmirror.com`（国内镜像，推荐）
- `jsd.onmicrosoft.cn`（国内镜像）
- `cdn.jsdelivr.net` / `fastly.jsdelivr.net` / `gcore.jsdelivr.net` / `testingcf.jsdelivr.net`
- `ghfast.top` / `ghproxy.net`（raw.githubusercontent 代理）

> 清单类请求优先走 raw 代理，避免 jsDelivr `@main` 缓存 12h+ 导致更新延迟。

## 插件端适配要求

- **最低插件版本**: v21.0.0（含引擎管理弹窗与自更新逻辑）
- **系统要求**: 已开启「高级功能(root)」、内核支持 `nf_conntrack_acct`
- **架构**: aarch64（引擎为静态链接，不依赖 libc）

---

## 安全与隐私

- 所有下载均通过 HTTPS + CDN，支持 md5 校验
- 插件自更新时校验 `_SIG` 身份标识，防止替换为恶意代码
- **不上传任何用户数据**（流量、MAC、IP 均保存在设备本地）

## 📡 OpenWrt 版「设备流量监控」(luci-app-devmon)

本仓库 `devmon/` 目录同时托管 **OpenWrt LuCI 版设备流量监控插件**（luci-app-devmon），适用于 OpenWrt 24.10+ / 25.x（apk 包管理）。

### 特性
- 纯前端 LuCI2 插件，**零常驻/零后台进程**；数据源 = OpenWrt 官方 nlbwmon（netlink 内核记账，不误统计）
- 总览卡片(下载/上传/合计/设备) + WAN 口实际消耗条 + 会话归因小字
- 设备排行（当前周期/累计历史）、历史按日、近 7/14/30 日趋势（柱状/折线）
- 设备改名（持久化 /etc/devmon.json）+ 每设备限速（nftables，fw4 重启保留）
- 云端更新：设置页「检查更新/立即更新」，内置多镜像自动回退（jsDelivr / ghfast / gh-proxy / raw）

### 安装
- OpenWrt 25.x：LuCI → 系统 → Software → Upload Package → 选 `devmon/luci-app-devmon_*.apk`
- 入口：服务 → 设备流量监控

### devmon 更新源
`devmon/latest.json` → `{ "version": "x.y.z", "apk": "…", "note": "…" }`
插件每次「检查更新」会拉取该清单并在有新版时提示一键升级。

与上方一致：AI 辅助生成，建议先在测试设备验证。
